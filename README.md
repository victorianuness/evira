## 🎯 Sobre o Projeto

Este repositório contém o planejamento, o relatório técnico sobre os frameworks **React** e **NestJS** (máximo de 2 folhas) e a aplicação prática de um **Quiz Técnico** construído com **React** em uma página HTML autônoma.

### ✅ Requisitos Implementados
* **20 Questões Técnicas** distribuídas entre **TypeScript** (7), **NestJS** (7) e **React** (6).
* **5 Alternativas (A–E)** por questão, com **única resposta correta**.
* **Sistema de Pontuação e Aprovação:** Contabiliza os acertos (0 a 20) e exige **mínimo de 70% (14 acertos)** para aprovação.
* **Gabarito Comentado:** Exibe telemetria de desempenho por tecnologia e revisão detalhada ao final.


2. Abra o arquivo `index.html` diretamente em qualquer navegador moderno (Chrome, Edge, Firefox).
